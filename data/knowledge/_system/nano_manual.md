# Nano 使用手册
## 手册对应Nano程序版本号：1.96

这是 Nano 自己的操作手册，记录界面上每个功能在哪、叫什么、怎么用。
用户问「XX 在哪」「怎么开关 YY」「能不能做 ZZ」时，答案应当来自这份文档。

---

## 打开设置面板

设置面板的入口是**窗口左上角那三个彩色圆点**（红、黄、绿）。点它们就会打开设置。

这三个圆点**不是窗口控制按钮**。最小化、最大化、关闭在窗口的**右上角**。

设置面板左侧有五个分类：**通用**、**个人信息**、**OS 权限**、**MCP 连接**、**进阶配置**。

---

## 设置 - 通用

「通用」页从上到下有五项：

- **语言**：调整 Nano 生成回复时的语言偏好。界面本身固定为简体中文，不受这里影响。
- **环境配置**：点右侧「配置」打开，用来填 API Key、中转地址、网络代理。详见下一节。
- **每日用量限额**：设置每天花费的软上限和硬上限。达到软上限时发出警告，达到硬上限时停止发送请求。旁边显示「今日已用」。金额是**估算**，实际以厂商官方后台的计费为准。
- **Token 计数器**：控制 Token 用量怎么显示，三个选项，详见下面「Token 计数器」一节。
- **导出数据**：把数据库里保留的全部对话记录导出到指定目录，包含已经重置掉的历史会话。

---

## 设置 - 环境配置（填 API Key、换厂商、中转、代理）

在「设置 → 通用 → 环境配置 → 配置」里。从上到下：

- **厂商**（必选）：下拉选择，左边是厂商图标，右边是厂商名。厂商决定了官方接口地址和 Key 的格式。
- **API Key**（必填）：填所选厂商的 Key。使用中转时填中转方发给你的 Key。
- **中转地址**：填了就走中转模式，留空就走厂商官方直连。
- **网络代理**：需要走代理访问接口时填这里。

保存之后，顶栏的主模型下拉会立刻跟着换成新厂商的模型列表，不需要重启。

如果顶栏出现「中转」标记，说明当前请求经过第三方中转，不是官方直连。

---

## 设置 - Token 计数器（三个选项分别是什么效果）

在「设置 → 通用 → Token 计数器」。三个选项：

- **不显示**：每条消息末尾只有计时器；右侧监控抽屉的卡片显示 `--`。
- **仅 Token**：每条消息末尾是计时器 + 这条消息的 Token 数；监控卡显示今日总 Token。
- **Token + cache hit**：每条消息末尾是计时器 + 这条消息的 Token 数 + 这条消息的缓存命中率；监控卡仍然是今日总 Token。

首次使用 Nano 时默认是「不显示」。

cache hit（缓存命中率）指送进模型的内容里被缓存复用的比例，比例越高越省钱。不同厂商的缓存机制不一样，命中率天然会有差别，不代表哪家更贵。

---

## 设置 - 个人信息

在「设置 → 个人信息」。填了之后 Nano 会用这些信息理解你的语境：

- **称呼 / 昵称**：Nano 偶尔会直接叫你的名字。
- **生日**
- **城市**（省 / 自治区 / 直辖市）
- **身份**：可选学生、上班族、自由职业、创业者 / 管理者、程序员 / 技术人员、设计 / 内容创作者、销售 / 市场、研究 / 学术、其他。

---

## 设置 - OS 权限

在「设置 → OS 权限」。这里是一组开关，控制 Nano 可以对这台电脑做哪些操作。标了「高危」的项需要格外谨慎。开关改动即时生效并写入配置文件。

---

## 设置 - MCP 连接（外接能力）

在「设置 → MCP 连接」。MCP 用来给 Nano 接入外部工具。

添加方式：点「添加 server」，从对方的文档里复制那段 JSON 配置粘进来，Nano 会自动校验并自动连接。支持**本地 stdio** 和**远程 HTTP** 两种类型。

每个已添加的 server 会显示状态：已连接、连接中、连接失败、需要登录、已禁用、未连接、正在重连。

---

## 设置 - 进阶配置（给不同工作分派不同模型）

在「设置 → 进阶配置」。这里可以给三类后台工作各自指定一个模型，和顶栏的主模型分开：

- **蒸馏**：把历史对话提炼成结论条目，用来压缩上下文占用。建议选低成本模型。
- **危险判定**：在 auto 模式下，判断 Nano 要执行的命令是不是与你的意图不符的危险命令，并适时拦截。建议选低成本模型。
- **视觉**：处理图片、PDF 扫描件这类多模态输入。

每一项的可选范围只包含**当前厂商确实支持这项工作**的模型。如果主模型本身没有视觉能力，Nano 会自动用这里指定的视觉模型去看图，再把看到的内容用文字带回对话。

如果这里是空的，说明还没填 API Key，先去「通用 → 环境配置」。

---

## 切换主题（把界面改成深色或浅色）

主题开关在**左侧工具面板的最底部**，显示当前主题名，点开可以切换。

两个主题：

- **默认**：浅色主题，暖白底 + 深色字。
- **终端**：深色主题，接近终端配色。

主题选择会被记住，下次启动仍然是你上次选的那个。

---

## 顶栏（模型选择、收藏、四个抽屉）

窗口顶部从左到右：

- **主模型下拉**：选当前对话用哪个模型。可选范围来自你在环境配置里选的厂商。
- **星号按钮**：把当前模型设为启动默认；再点一次取消。
- **[知识库]**、**[监控]**、**[任务]**、**[记忆]**：四个抽屉的开关，点一下从右侧滑出。

---

## 知识库抽屉（上传文件、检索、删除）

点顶栏 **[知识库]** 打开。分三块：

**入库设置**
- **增强模式**：开关。开启后入库时做更细致的处理，速度更慢但检索质量更好。
- **OCR 页数上限**：滑块。限制扫描件最多识别多少页，防止一份超长 PDF 占满时间。

**添加文档**
支持的格式：txt、md、pdf、docx、pptx、xlsx、csv、jpg、png、webp。可以拖进虚线框，也可以点「添加文件」。

**已索引文件**
显示已入库的文件数和知识块数。每个文件右侧的 ⋮ 菜单里有「查看内容」和「删除」。右上角有刷新按钮。

---

## 监控抽屉（今天花了多少、状态是否正常）

点顶栏 **[监控]** 打开。里面有：

- **系统监控**：内存、CPU 占用。
- **系统状态**：当前模型、互联网检索是否可用、知识库 RAG 是否可用、全文加载是否可用、环境是否正常。
- **今日 Token**：今天累计消耗，显示方式由「设置 → 通用 → Token 计数器」控制。
- **消费金额**：今日估算花费。
- **上下文**：当前对话占用了多少上下文。
- **执行日志**：Nano 正在做什么的实时滚动。

---

## 任务抽屉

点顶栏 **[任务]** 打开，列出正在后台跑的任务。没有任务时显示「当前没有在跑的后台任务」。

---

## 记忆抽屉

点顶栏 **[记忆]** 打开，查看 Nano 从对话里记下来的内容。

---

## 工具面板（左侧 ~/tools）

窗口左侧是工具面板，标题是 `~/tools`，上方有搜索框。

每个工具一行：名称、来源标签（官方工具带「官方」标记）、运行状态（READY 表示就绪）。

每个工具右侧的 ⋮ 菜单里有四项：**查看说明**、**查看源码**、**禁用**、**删除**。

内置的官方工具包括：Base64 编解码、获取系统时间、哈希生成、正则测试、网页搜索、用浏览器打开网页。

---

## 输入框下方的两个控件（Auto 模式 和 主动程度）

输入框下方左侧是 **Auto** 芯片，右侧是**主动程度**下拉。

**Auto 芯片**有两个选项：
- **Ask permission**：Nano 要动手做事之前先问你。
- **Auto mode**：Nano 自己判断并直接执行。

**主动程度**有三档：
- **Low**（偏安静）
- **Medium**（均衡）
- **High**（更主动）

这一档控制 Nano 主动开口、主动做事的倾向，不影响它回答问题的能力。

注意：截止 1.96 版本，主动开口模块依旧属于测试阶段（影子模式），它本身并未实装，这个主动程度档位没有任何实际影响。
---

## 发图片给 Nano（上传、粘贴、回看）

三种方式都可以：直接粘贴（Ctrl+V）、点输入框右侧的上传按钮、把文件拖进来。

图片会被保存下来。之后你再追问图里的细节时，Nano 可以重新去看那张原图，不需要你重新发一遍。

如果当前主模型本身没有视觉能力，Nano 会自动调用「设置 → 进阶配置 → 视觉」里指定的模型替它看，然后把看到的内容用文字带进对话。

---

## 为什么rag（知识库）检索速度很慢？
只有「第一次」会慢，之后恢复正常速度，慢的原因有三：首次检索需要加载嵌入模型（BGE-M3，约 2.3 GB）和重排模型（首次约 30 秒）；BM25 索引会在首次检索时重建（几千片段约几秒）。另外，第一次启动时如果知识库有文件需要入库、或本地还没有模型文件需要下载，这些工作也会在启动阶段完成，所以首次启动偏慢同样是正常的。这些都只发生一次。

## Nano是否会收集用户的个人信息

Nano 收集电脑使用轨迹，但仅用于本地运行。具体规则如下：

- **环境轨迹**：只记录「应用 + 在做什么」的一行摘要（如「Chrome 正在浏览某网页」），不存储原始事件或内容明文，18 小时后自动过期  
- **行为账本**：使用封闭类别标签记录操作（如「文件操作」「网络访问」），禁止存储任何语义化敏感信息  
- **数据存储**：所有数据均保存在本地 `data/` 目录，不会上传至云端或第三方服务  
- **遥测**：无遥测功能，不收集使用统计或用户行为数据（ChromaDB 的匿名遥测已禁用）

---

## Auto模式是否安全：

Auto 模式并非默认跳过所有确认弹窗，系统里有一个独立的命令判定器，在 `run_command` 执行前做一道实时安检：

- **80%+ 的常规命令**（如查状态、读文件、运行普通工具）不进判定，直接运行。
- **高危操作**（删除、覆盖、安装/卸载、杀进程、改系统/注册表、外传数据等）进入意图核对：
  - 用户刚才明确要求做这件事 → **放行**（如你说“清理临时文件”，删临时目录就自动运行）。
  - 用户没要求做这件事 → **弹窗拦截**，等用户确认再执行。
> **危险不是命令的属性，是“动作偏离了意图”的属性。**

## Nano 怎么查自己的手册

这份手册存放在知识库的 `_system/` 目录下，文件名是 `_system/nano_manual.md`。

它**不出现在知识库抽屉的文件列表里**，也不能被删除按钮删掉——这是刻意的，防止误删。但它对 Nano 自己是可见的，而且**已经进了 RAG 索引**。

两条查询方式都可用，按问题挑：

- 问题里的关键词明确（例如「切换主题在哪里切换」），用 `query_local_knowledge` 检索片段就够。
- 问法比较绕、关键词难命中（例如「有没有办法把页面改成黑的」），检索不到有价值内容时，用 `load_full_file` 读全文。文件名要写完整的 `_system/nano_manual.md`。
