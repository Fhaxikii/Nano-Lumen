# 01 · 安装与启动

**这篇讲什么**：环境要求、安装、启动，以及第一次对话需要的最小配置。  
**读完你能做什么**：在本机把 Nano 安装、启动并完成一次对话。  
**前置**：无。  

> 语言：中文 · [English](../en/01-getting-started.md)

---

## 环境要求

- Windows 10 或更高版本。项目使用 WebView2 作为渲染层，并依赖若干 Windows API，
  目前不支持其他操作系统。
- Python 3.10。版本敏感：代码中存在 3.10 特有的写法约束，
  更高版本未经验证。
- 磁盘空间约 6 GB。其中嵌入模型 `BAAI/bge-m3` 单个文件约 2.3 GB。
- 可用内存建议 8 GB 以上。加载嵌入模型时需要一次性提交约 2.3 GB，
  内存不足会导致知识库检索不可用（错误处理见 `core/rag.py` 的
  `_classify_model_load_error`）。

## 安装

```
install.bat
```

该批处理会调用 `install.ps1` 执行实际安装逻辑。依赖清单是 `requirements_cpu.txt`，
它由一个可正常运行的环境 `pip freeze` 导出，版本号逐一对齐。

修改依赖时应重新导出覆盖该文件，不要手工编辑版本号。

PyTorch 使用 CPU 版本，安装脚本已附加对应的额外索引源。

## 下载嵌入模型

知识库检索依赖本地嵌入模型，需要单独下载：

```
py -3.10 _setup_rag_models.py
```

该脚本支持断点续传。没有这个模型时 Nano 仍可正常对话，只是知识库检索不可用。

## 启动

```
start.bat
```

等价于在项目根目录执行 `python app.py`。

## 第一次对话需要的配置

启动后，点击窗口左上角的三个彩色圆点打开设置面板，进入
「通用 → 环境配置」，至少填写两项：

- **厂商**：选择模型提供方。
- **API Key**：所选厂商的密钥。

配置会写入项目根目录的 `.env`。也可以直接编辑该文件，可用的键见
[03-configuration.md](03-configuration.md)。

## 常见问题

**知识库检索不可用，提示模型文件缺失**
先确认 `~/.cache/huggingface/hub/models--BAAI--bge-m3/` 下的
`model.safetensors` 是否存在且大小约 2.27 GB。文件完整而仍然失败时，
通常是内存不足，此时错误信息会明确说明「文件完好，不需要重新下载」。

**启动后界面空白**
检查控制台输出。渲染层是 WebView2，需要系统已安装 Microsoft Edge WebView2 Runtime。

**为什么装完要下载 2GB 的东西？**
那是本地嵌入模型（bge-m3），用来做知识库 RAG 检索，不是你的 LLM。它完全在你本地运行，已关闭遥测。如果不用知识库功能，可以跳过这步，UI 会提示环境缺失，属于预期内现象。

**设置菜单在哪？**
设置入口是窗口左上角那三个彩色圆点（红、黄、绿）。

**对话历史和记忆存在哪里？**
全部存在你本地的 `data/` 目录下，不上传云端，想清空的话直接删那个目录就行。可以在设置菜单中导出可读的历史对话。

**我该如何使用这个软件？新手引导在哪里？**
Nano 没有传统意义上的新手引导，它内置了自身可查阅的操作手册，你不需要翻任何教程，直接问它就行："设置菜单在哪""怎么开 OS 权限""怎么导出对话"，它自己就知道答案。

**它会抓取我操作电脑的轨迹吗？有没有隐私泄露风险？**
Nano 会采集最小必要的行为元数据来做轨迹感知：前台窗口 / 进程切换、键盘事件（只记按键类型如 Ctrl+S / Backspace，不记你打的是什么字）、CPU 采样。所有轨迹只存「应用 + 在做什么」的一行摘要，不存原始事件和内容明文，18 小时后自动过期清除。全部数据在本地，不上传云端。

## 怎么验证你改对了

1. `start.bat` 能启动且窗口正常渲染。
2. 完成一次对话并收到回复。
3. 运行测试：`bash run_tests.sh`，期望输出 `OK 真·全量 0 失败`。
   若唯一失败项是 `tests/t_f5_live.py` 且返回码为 139，通常是加载嵌入模型时
   内存不足导致的进程崩溃，与代码改动无关。
