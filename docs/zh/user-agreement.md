## 2. 软件性质

本软件是一个常驻于 Windows 桌面、具备以下能力的开源智能体：

- 执行操作系统命令与桌面自动化操作（含文件创建、修改、移动、删除）
- 编辑与读写本地文件
- 调用你自行配置的第三方模型 API（产生费用）
- 加载并运行本地及第三方扩展（技能、MCP server）

本软件内置多层安全机制（风险分级、权限开关、命令分类器、敏感路径策略），**但任何安全机制都不能保证绝对不发生误操作、数据丢失或非预期行为**。安全机制降低风险，不消除风险。
